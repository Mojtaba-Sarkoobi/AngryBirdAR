# AngryBirdAR

*An Augmented Reality game to defend your safe zone from incoming birds.*

## Gameplay Overview
https://github.com/user-attachments/assets/d594909e-44ec-4400-9a45-64c306a5ace5

This gameplay video demonstrates birds spawning on the left and moving to the right. Players must shoot the birds within the designated safe zone. If a bird escapes this zone, the player loses health. As the player levels up, both bird speed and spawn rates increase.

## Core Features
* **Progressive Difficulty:** Dynamic spawn rates and bird movement speeds that scale with the player's level.
* **Survival Mechanics:** Penalty-based health system tied to the spatial safe zone.
